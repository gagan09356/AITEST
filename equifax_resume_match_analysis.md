## Add these items if they are true

1. **Exact degree:** qualification, subject, university, location, and graduation year. The current education entry is incomplete.
2. **Cloud evidence:** provider, services, production use, architecture, scale, and dates. State “5+ years” only if the timeline supports it.
3. **Containers and infrastructure as code:** Kubernetes/GKE, Docker, Helm, Terraform, and Jenkins pipeline ownership, each tied to a work achievement.
4. **AI-assisted engineering:** name the tools used and describe a real outcome—for example test generation, code review, debugging, documentation, or an agentic/tool-calling prototype with guardrails.
5. **Frontend evidence:** TypeScript, CSS, Angular, or Bootstrap only where used in real work; add the relevant project bullet.
6. **Testing depth:** REST Assured, Selenium, Playwright, integration/contract tests, test coverage, and quality-gate results if applicable.
7. **Measured impact:** throughput, latency, deployment time, defect reduction, test coverage, database-load reduction, migration volume, uptime, number of services, or team size.
8. **Professional links:** LinkedIn and GitHub/portfolio if polished and relevant.
9. **Work authorisation:** if useful and accurate, state Irish/EU work authorisation or that no sponsorship is required.
10. **Cloud certification:** add an earned AWS/GCP certification; do not list one that is merely planned.
